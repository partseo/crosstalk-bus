# CrossTalk Bus — CTS ↔ 외부 검토 조정 버스

CTS(CrossTalk System)가 내부 협의로 만든 **확정 지시서**를 여기 올리면,
외부 검토자(GPT 챗 / Claude 챗)가 읽고 **완료요건 기준**으로 검토합니다.

## 흐름
```
CTS 내부 협의(gemini 마스터 등) → 확정 지시서 → 이 리포에 커밋
   → 외부 챗(GPT/Claude)이 읽고 검토 (최대 3 사이클)
   → [완료요건 충족: 최종 확정] 이면 CTS가 개발 착수
```

## 폴더
- `확정지시서/` — CTS가 올리는 확정 지시서 (검토 대상)
- `검토/` — 외부 챗의 검토 결과 회신

## 외부 검토자 규칙
- 완료요건을 충족하면 마지막 줄에 단독으로: `[완료요건 충족: 최종 확정]`
- 부족하면 보완점 3개 이내로. 매 사이클 새 트집 금지(수렴 우선).
- **최대 3 사이클**. 3회째엔 반드시 확정 또는 "사람 결정 필요"로 종료(무한루프 방지).
