# 확정 지시서 — KAKAO-SYSTEM (T-004)

> CTS 내부 협의 결과 · 마스터: Gemini CLI · 단계: 지휘
> 외부 검토 요청: 아래 조건이 완료요건으로 충분한지 검토. 부족하면 보완점 3개 이내.

## 무엇
대상 채팅방 진입 로직(UI Automation 적용) 및 안전한 클립보드 제어 모듈 구현.

## 왜
대상 채팅방을 오작동 없이 정확하게 열고, 발송 시 사용자의 기존 클립보드 복사 데이터를 보호하기 위한 필수 기반 작업.

## 조건
- **방 진입 최적화**: `window_manager`를 활용해 이미 열려있는 창을 우선 탐색하고, 없을 경우 `comtypes` 기반 UI Automation으로 채팅 목록에서 이름으로 대상을 찾아 실행(스크롤/좌표 계산 배제).
- **클립보드 보호**: `ClipboardSetTextSafe` 명세에 따라, 현재 클립보드 내용 백업/복원 + STA 스레드 환경 충돌 방지 및 재시도 처리를 포함한 래퍼 모듈(`clipboard_util.py`) 작성.
- **테스트 모드**: `ks.py` 명령행 옵션으로 특정 채팅방 이름으로 창을 여는 기능과 클립보드 복원 상태를 점검할 수 있는 테스트 모드 추가.

## 담당
Claude CLI (실행자)

## 파일
`window_manager.py`(또는 신규 `chat_manager.py`), `clipboard_util.py`, `ks.py`
